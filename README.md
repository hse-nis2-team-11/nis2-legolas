## Сокращённый запуск

Требования к хосту:

- Возможность выделить контейнеру примерно 4 CPU и 8 GiB RAM.
- Linux x86-64 и Bash.
- Docker.
- Доступ в интернет.
- Достаточный запас свободного диска под образ, кэш сборки и результаты, 10 Гигабайт.

Из корня репозитория:

```bash
DOCKER_BUILD_NETWORK=host bash scripts/checkpoint-1/docker.sh build # собрать образ
bash scripts/checkpoint-1/reproduce.sh # воспроизвести сценарий КТ-1
```

Результаты сохраняются в каталоге `.local/reproductions/`. Описание технических проверок и полученные результаты приведены в [отчёте КТ-1](nis/checkpoints/01.md).
